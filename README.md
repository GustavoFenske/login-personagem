# 🎭 Login de Personagem

Interface de login desenvolvida em dupla, utilizando um personagem escolhido para definir a identidade visual da página.

## 📌 Sobre o projeto

O projeto combina uma interface temática com uma tela de login, utilizando HTML, CSS e JavaScript.

## 🛠️ Tecnologias

- HTML5
- CSS3
- JavaScript

## 🎯 Objetivo

Praticar a criação de interfaces e a integração de elementos visuais com funcionalidades utilizando JavaScript.

## 👥 Desenvolvimento

Projeto desenvolvido em dupla.
